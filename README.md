# 📈 Tordin Trade

**Plataforma de análise de criptomoedas e simulação de trading.**

O **Tordin Trade** é um projeto em desenvolvimento criado com o objetivo de oferecer uma experiência moderna de análise do mercado financeiro, com gráficos interativos, cotações de criptomoedas e ferramentas para simular operações de compra e venda.

A plataforma busca proporcionar uma interface intuitiva, inspirada em terminais profissionais de trading, permitindo acompanhar as movimentações do mercado e explorar funcionalidades de análise gráfica.

## 🚧 Status do Projeto

**Em desenvolvimento — Work in Progress.**

O projeto ainda está em evolução e recebe melhorias contínuas em sua interface, funcionalidades, desempenho e estabilidade. Algumas funcionalidades ainda estão sendo planejadas ou implementadas, portanto, esta versão não representa necessariamente a versão final da plataforma.

## ✨ Funcionalidades

- 📊 Gráficos interativos de candles.
- 📈 Cotações e dados de mercado de criptomoedas.
- 🔄 Atualização de preços por meio de integração com a API da Binance.
- ⏱️ Diferentes intervalos de tempo para análise gráfica.
- 🛠️ Indicadores e ferramentas de análise técnica.
- 💹 Simulador de operações de compra e venda.
- 💰 Conta demonstrativa com saldo virtual e histórico de operações.
- 🎨 Interface moderna, com foco na experiência do usuário.

## 🛠️ Tecnologias

- **React 19** — construção da interface.
- **TypeScript** — tipagem e segurança do código.
- **TanStack Start** — estrutura da aplicação.
- **Vite** — ambiente de desenvolvimento e build.
- **Tailwind CSS** — estilização da interface.
- **Lightweight Charts** — visualização de gráficos financeiros.
- **Binance API** — obtenção de dados de mercado.
- **Vitest** — testes automatizados.

## ▶️ Como executar o projeto

É necessário ter o Node.js 22 ou superior e o npm instalados.

```bash
# Clone o repositório
git clone URL_DO_SEU_REPOSITORIO

# Entre na pasta do projeto
cd nexus-trade-pro

# Instale as dependências
npm install --legacy-peer-deps

# Inicie o ambiente de desenvolvimento
npm run dev
```

Após iniciar, acesse o endereço local exibido no terminal.

## ⚠️ Aviso

O Tordin Trade é um projeto em desenvolvimento, voltado à análise de mercado e à simulação de operações. O simulador utiliza saldo demonstrativo e **não executa ordens financeiras reais**. As cotações dependem da disponibilidade dos serviços externos e podem apresentar atrasos ou interrupções.
